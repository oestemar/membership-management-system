# テスト手順

## 1. テストに必要な情報
- 会員画面 URL：
https://membership-management-system-production.up.railway.app/
- テスト用メールアドレス → 任意のメールアドレスで登録可能 
※ 登録完了メール・パスワードリセットメール・退会完了メールが実際に届く
- データ削除について
退会後、デモ管理者でログインすればご自身の会員情報のみ削除可能
※削除時は確認画面が出るので「会員登録時のパスワード」を入力してください
- 推奨ブラウザ → Google Chrome / Microsoft Edge
- デモ用管理者アカウント（ＩＤ：demo、PW：test）
## 2. テストの流れ（約 10 分）
採用担当者が迷わないように、 「登録 → ログイン → 編集 → パスワード変更 → 休会 → 再開 → 退会　→　管理者で削除」 という “会員の一連のライフサイクル” を短時間で確認できる構成にする。
## 3. テスト手順（会員側）
### ① 会員登録（新規登録）
- 1.URLにアクセスする
- 2.「会員登録」をクリック
- 3.以下を入力　
  - 氏名
  - メールアドレス
  - 郵便番号（例：1000001）
  - 住所（検索ボタンで途中まで自動入力される）
  - 電話番号（任意）
  - パスワード
- 4.「登録」ボタンを押す　※バリデーション機能がある
- 5.登録完了メッセージが表示され、ログイン画面へ遷移する
- 6.入力したメールアドレスに「登録完了メール」が届く
### ② ログイン
- 1.登録したメールアドレスとパスワードを入力
- 2.「ログイン」ボタンを押す
- 3.マイページが表示される
### ③ 会員情報の確認
- マイページに以下が表示される
  - 氏名
  - メールアドレス
  - 郵便番号
  - 住所
  - 電話番号
  - 会員ステータス（活動中）
### ④ 会員情報の編集
- 1.「会員情報を編集する」をクリック
- 2.氏名・住所などを変更
- 3.「更新」ボタン　※バリデーションあり
- 4.マイページに戻り、変更内容が反映されていることを確認
### ⑤ パスワード変更
- 1.マイページの「パスワード変更」をクリック
- 2.現在のパスワード、新しいパスワードを入力
- 3.「変更」ボタンを押す
- 4.完了メッセージが表示
- 5.新パスワードで再度ログインできることを確認
### ⑥ 休会 → 再開
- 1.「休会する」をクリック
- 2.ステータスが「休会中」に変わる
- 3.「再開する」をクリック
- 4.ステータスが「活動中」に戻る
### ⑦ 退会
- 1.「退会する」をクリック
- 2.退会完了メッセージが表示され、ログイン画面へ戻る
- 3.退会したアカウントではログイン不可
- 4.「退会完了メール」が届きます
### ⑧ パスワードを忘れた場合
- 1.「パスワードを忘れたら」をクリック
- 2.表示されたページで自分のメールアドレスを入力
- 3.送信ボタンクリック
- 4.自分のメールアドレスにパスワードリセットメールが届く
- 5.自分のメールアカウントに届いたメールを開いて、URLをクリックする
- 6.新しいパスワードと確認用パスワードを入力して登録ボタンをクリック

### ⑨ 管理者ログイン
- 1.「管理者ログイン」をクリック
- 2.ＩＤ：demo、PW：testを入力
- 3.ログインボタンクリック
- 4.管理者画面が開く
### ⑩ 管理者画面：検索
- 1.何も入れず検索ボタンを押す→全会員一覧表示されるt
- 2.「ステータス」を「退会」にして検索→退会者のみ表示
- 3.詳細ボタンを押すと、内容表示される
- 4.自分の退会済アカウントの詳細も確認可能
### ⑪ 管理者画面：編集
- 1.詳細表示の下に、編集ボタンがある
- 2.押すとdemo管理者は、会員登録時のパスワードをきかれる
- 3.会員登録時のパスワード（ご自分で決めたもの）を入力して確認ボタンを押す
- 4.編集が出来る（編集できるのは自分の会員情報のみ）
- 5.会員情報を修正して登録ボタンを押すと反映される
### ⑫ 管理者画面：削除
- 1.詳細表示の下に削除ボタン
- 2.押すとdemo管理は、会員登録時のパスワード入力が必要
- 3.パスワードを入力→「削除を進める」
- 4.削除完了
### ⑬　管理者画面：その他機能
- 1.CSVインポートは「権限無し」で不可
- 2.CSVエクスポートボタンでCSVをダウンロード可能
- 3.パスワード変更は「権限無し」で不可
- 4.ログアウトで管理者画面から出る
